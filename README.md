## 运行
使用Python3.12，在本目录建立独立环境并按requirements.txt安装依赖。不要在私密原工程内运行初始化。

```
python scripts/bootstrap_demo.py --synthetic-only
python -m streamlit run app/public_demo.py --server.address 127.0.0.1 --server.port 8515
```

Windows已有配套解释器时也可用run_python.ps1执行上述参数，再用start_demo.ps1启动。首次初始化仅生成24条合成数据、训练及验证，再建立独立版本库；不会访问真实XLSX。初始化拒绝覆盖已有模型或数据库。生成的models/reports/local_store不可随公开仓库提交。

录制只使用8515合成演示页。页面不展示编号、批次、内部路径和逐条审核历史。预测及图解可交互；更新流程标签显示流程说明，不把它冒充实际审核操作。审核、候选、比较及回滚实现保留于src和app/workflows.py，需在隔离库中主动调用，不自动启用模型。合成记录不应声明为新增真实实测。

## 合成公式与复现边界
剂量为2、4、6、8，温度为140、180、220，每个条件两条，偏移符号s取-1和1。
- 比容量=120+14d-1.2d²+0.12(T-140)+3s。
- 循环稳定性=260+16d-2d²+0.45(T-140)+8s。

这些公式不来自原研究的回归、分布或目标值。随机种子和固定核设置只为复现软件行为；名义90%区间不是未来覆盖保证。
